# Replacement question protocol

Use assets/replacement-options-template.md. For each original parent question marked CONSIDER REPLACING, create exactly four meaningfully different OPTIONAL replacement questions labeled A–D. Never create a revised CUA or insert options into the original.

## Required fields for every option

- Complete question and necessary directions, data, visuals, and response requirements.
- Complete answer/answer key, worked solution, and applicable scoring criteria. Enumerate all correct selections for multi-select; state permitted equivalents or defensible responses for open tasks.
- Standard/substandard using exact uploaded S1 identifiers and citations.
- Target skill/content and connection to the documented concern.
- Estimated Webb DOK with a task-specific rationale.
- Item type.

Provide four distinct approaches, representations, response demands, or evidence opportunities. Merely changing numbers, names, or contexts in the same question is insufficient. Compare the four options explicitly to check meaningful variation. Stay grade-appropriate and within uploaded unit expectations; a source-supported coverage correction may intentionally change the target, but must explain why and identify lost coverage.

Recommend exactly one option for each flagged original question. Explain specifically how it improves the overall assessment: which gap, redundancy, reasoning mismatch, design problem, accuracy problem, or balance concern it addresses; what mastery evidence it adds; what existing evidence is retained or lost; and why it is preferable to the other three. Do not justify it only as harder. Do not present four mutually exclusive options as four additions to coverage totals.

## Independent verification

Solve each generated question independently from its proposed key before comparing results. Recompute by another method or direct substitution where useful. Verify mathematical accuracy, one defensible correct answer when appropriate, complete permissible answers otherwise, units, diagrams, distractors, scoring, grade-level appropriateness, source-standard alignment, clarity, and appropriate DOK classification. Record correction and recheck any option that fails. Do not call an unverified key correct.

Create original questions rather than copying secure external assessment items. Every necessary visual must be mathematically checked and fully conveyed within the copy-ready report block by a text diagram/data table or an exact figure specification determining all geometry, labels, scale, partitions, shading, and plotted values. Inspect internally rendered figures when used for verification; do not depend on external images surviving the copy. Student-created figures need complete construction directions and all provided axes/data. ChatGPT may typeset the verified specification but must not supply missing data, reinterpret the mathematics, or verify answers on Codex's behalf. No unresolved visual placeholders are allowed. If source evidence or an unresolved mathematical representation prevents valid options, state the concrete blocker and do not fabricate options or claim completion. Lack of PDF generation or rendering tools alone does not block a complete text representation. When no questions are flagged, still provide the third copy-ready report block with an explicit no-replacements-needed statement.
